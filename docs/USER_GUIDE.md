# Autopilot Console 使用指南

Autopilot Console 是一款简单、安全、去中心化的网格虚拟局域网（Mesh VPN）的图形化管理与监控控制台。本指南旨在帮助您快速上手，完成网络组建与高级特性的配置。

## 1. 快速入门

### 1.1 登录与鉴权
- 打开 Autopilot Console，使用您的账号与密码登录系统。
- 登录后，系统将自动进入主控制面板（Dashboard），默认会显示名为 `default-mesh` 的主控网络状态。

### 1.2 创建与管理虚拟网络
- **创建网络**：点击左下角（或右上角图标）打开“网络管理与切换”面板，点击“新建虚拟网络”。输入网络名称、虚拟 IPv4/IPv6 网段（如 `10.144.144.0/24`）以及认证密钥（PSK）后保存。
- **切换网络**：在网络管理弹窗中，点击指定网络卡片右上角的“切换为此网络”即可将控制台视图切换至该网络。
- **删除网络**：在网络列表的卡片中点击红色的删除图标即可移除网络配置。注意：当系统中仅剩一个网络时无法删除。

### 1.3 添加设备入网
1. 在“网络拓扑”或“节点列表”视图中，点击右上角的“添加设备”。
2. 系统会自动生成针对当前网络配置的“一键接入指令”（如 `curl ... && mesh-core --ipv4 ...`）。
3. 复制并在您的 Linux / macOS / Windows 设备上执行该指令即可实现零配置加入网络。

## 2. 核心功能说明

### 2.1 仪表盘与可视化
控制台提供了多种直观的可视化手段来帮助您掌握整体组网情况：
- **实时数据看板**：包含在线节点数、链路延迟、入网出网总流量、P2P 直连打洞率等关键指标（动态响应网络活动）。
- **网络拓扑视图**：提供类似“星际拓扑”的结构图，实时反映全网节点的连接状态（直连 P2P、中继转发）及链路延迟。
- **3D 数字地球视图**：依据节点 IP 与地理位置，在 3D 地球仪上绘制跨国链路与空间拓扑。

### 2.2 子网路由 (Proxy CIDR)
用于实现内网穿透与“点对网”互联：
- 进入左侧边栏的 **子网路由 (Proxy CIDR)**。
- 您可以查看或添加基于节点的子网路由规则。例如，让某台拥有公网 IP 的节点，将 `192.168.1.0/24` 的流量透明转发进入 Mesh 虚拟网，其他节点就能直接访问该节点背后的局域网设备。

### 2.3 STUN 穿透与中继
如果两个设备都在复杂的 NAT 环境（如对称型 NAT）下，P2P 直连可能会失败。
- **STUN 探测服务器**：在左侧边栏的 **STUN 穿透与中继** 面板中，配置外部公共或私有的 STUN 服务器地址，系统将利用这些服务器协助节点间穿透 NAT 并建立 UDP 直连。
- **中继节点 (Relay Hubs)**：如果无法打洞成功，系统将通过这里配置的中继节点进行流量加密转发，保障连通性兜底。

### 2.4 安全策略 (ACL)
限制哪些节点可以互相访问，打造微隔离（Micro-segmentation）的零信任网络：
- 在 **访问控制 (ACL)** 面板中，您可以按需制定策略。支持通过节点 Tag、CIDR 甚至是节点特定协议（TCP/UDP）及端口限制网络互相访问行为。
- 系统提供可视化的规则拖拽排序机制（顺序匹配、默认放行/拒绝）。

## 3. 高级节点特性
高级功能面板专为有自定义和复杂场景需求的专业用户设计。点击侧边栏左下方的 **“高级节点功能”** 进入。

1. **无 TUN 模式 (免 Root 权限)**：以非特权用户运行进程，只能被动接受访问，适用于无系统最高权限的容器/服务器环境。
2. **魔法 DNS (Magic DNS)**：自动劫持 `.mesh.local` 后缀的请求，支持您在未记忆节点 IP 的情况下，直接通过 `主机名.mesh.local` 访问对应节点。
3. **开机自启**：一键将核心服务注册至宿主机系统（Systemd 或 Windows Services）。
4. **Secure Mode (安全模式)**：对所有的 P2P/中继报文开启二次 AES-GCM 加密，彻底杜绝数据在互联网和中继链路中被截获分析的风险。
5. **协议代理接入**：
   - **WireGuard 客户端接入**：开启后，节点会开放标准的 WireGuard UDP 服务端口，手机端可以通过 WireGuard 官方客户端直接连入 Mesh 局域网。
   - **SOCKS5 端口转发**：开启后，会在节点本地监听一个 SOCKS5 代理端口，将所有代理请求透明转发入虚拟内网。
6. **带宽延迟优化 (KCP/QUIC 代理)**：专为跨境、弱网和高丢包环境设计。它将底层的 TCP 流量封装进自适应抗丢包的 KCP 或 QUIC 协议传输，能够极大改善跨国节点或高延迟情况下的实际吞吐表现。
